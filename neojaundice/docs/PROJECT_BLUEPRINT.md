# PROJECT BLUEPRINT

## Project Title

Neonatal Jaundice Screening and Bilirubin Level Estimation Using Smartphone Skin Images

---

# Vision

Build a production-grade AI healthcare platform capable of:

- Neonatal jaundice screening
- Bilirubin level estimation
- Severity classification
- Explainable AI visualization
- FastAPI deployment
- React frontend
- PostgreSQL storage
- Docker deployment
- MLflow tracking
- DVC versioning
- ONNX/TFLite export

---

# Objectives

## Primary Objectives

1. Detect neonatal jaundice.
2. Estimate bilirubin levels.
3. Classify severity.
4. Provide visual explanations.
5. Support real-time inference.

## Secondary Objectives

1. Production deployment.
2. MLOps integration.
3. Research publication readiness.
4. Placement interview readiness.
