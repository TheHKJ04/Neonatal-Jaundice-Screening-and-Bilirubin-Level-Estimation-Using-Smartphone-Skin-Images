# NeoJaundice AI

AI-powered neonatal jaundice screening and bilirubin estimation system using smartphone images.

---

# Features

- Jaundice Detection
- Bilirubin Estimation
- Severity Classification
- GradCAM Visualization
- FastAPI Backend
- React Frontend
- PostgreSQL Integration
- MLflow Tracking
- DVC Dataset Versioning
- Docker Deployment

---

# Technology Stack

Frontend:
React + TypeScript

Backend:
FastAPI

Machine Learning:
PyTorch

Computer Vision:
OpenCV + MediaPipe

Database:
PostgreSQL

MLOps:
MLflow + DVC
